# Cursus v0.0.3

Android preview and a Linux/Android checkpoint.

- Independent Chats, Channels, Calls and Settings panes; consistent back navigation and Android system back handling.
- Shared settings styling, improved phone/tablet layouts, Linux touch menus, image previews and clipboard image attachments.
- Swipe cancellation for buttons: scrolling no longer activates the button under the release point.
- Faster cached call history and consistent call icons.
- Rich profile text, multiline group/channel descriptions and all eight supported emoji reactions.
- Code audit: consolidated asynchronous Android loaders, fixed duplicated row modifiers, handled notification permission revocation, removed unused icons and unreachable Linux handlers.

## Android preview

`cursus-android-arm64-v8a.apk` requires Android 8.0 (API 26) or newer and
64-bit ARM. It includes the pinned official SimpleX Android core v7.1.0.
Android audio calls are not implemented yet; call history is available.

This checkpoint uses debug signing, not a production distribution key.
CI generates a new debug key for each release. Installing over a locally
built APK or a previous release may fail with a signature mismatch.
Back up your data before any uninstall; uninstalling removes local app data.
For installations that need reliable upgrades, build subsequent versions
with the same local signing key. Device testing remains necessary.

SHA256SUMS accompanies the release assets. The tag's GitHub workflow builds
both Linux architectures and the Android APK, then publishes them together.

## Checkpoint validation

195 Rust workspace tests passed; 20 optional integration/screenshot tests
remain ignored. Workspace Clippy passes with warnings treated as errors.
Android debug and release lint have no errors; remaining warnings concern
complex icon paths and the intentional ARM64-only ABI. Six Android unit
tests pass in each variant. The release APK builds, verifies its signature,
and reports version 0.1.2 (102); the tag was later renumbered from v0.1.2 to v0.0.3.

Physical device testing, macOS builds and GitHub's Linux ARM64 packaging
still require their respective devices/runners. Local Linux test linking
used reduced debug information to fit the available memory.
