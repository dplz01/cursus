# Cursus v0.0.4

Release numbers now start from 0.0.x: the earlier v0.1.0, v0.1.1 and
v0.1.2 are now v0.0.1, v0.0.2 and v0.0.3 (same code, renamed tags).

## What's new

- **Audio calls on Android** through the shared native WebRTC engine, plus a fix for a crash during calls.
- **Glass floating bars** on Linux and Android: the navigation dock, chat title bar, composer and profile bars float over content with a real blurred backdrop.
- **Page transitions** across clients, and Android **predictive back**: the page follows the gesture and slides away when released.
- **Clock preferences** (12/24-hour) across clients.
- **Group DM requests**: accept or reject direct messages from group members; read positions are restored when reopening a chat.
- **Settings** in plain language, with flat row groups, consistent back controls and folded profile "about" sections.
- **Markdown** bold syntax matches SimpleX; inline code is styled consistently on Linux.
- **Faster** chat, media, calls and Connect screens; improved media preview edges.

## Fixes

- **Calls page error "no support chat"**: call history no longer fails when a group still holds items from a deleted member support chat. History now reads only call items, and skips any chat the core can't load.
- **Linux voice messages**: pressing the microphone in the composer starts recording again.
- **Android**: navigation label spacing and font scaling.

## Android preview

`cursus-android-arm64-v8a.apk` requires Android 8.0 (API 26) or newer and
64-bit ARM. It includes the pinned official SimpleX Android core v7.1.0.
It reports version 0.0.4 (1004): the version code keeps increasing across
the renumbering, so it installs over v0.0.3 (102) when the signature matches.

This checkpoint uses debug signing, not a production distribution key.
CI generates a new debug key for each release. Installing over a locally
built APK or a previous release may fail with a signature mismatch.
Back up your data before any uninstall; uninstalling removes local app data.

SHA256SUMS accompanies the release assets.
