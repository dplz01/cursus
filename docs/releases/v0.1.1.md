## What's new in 0.1.1

Linux only. Bug fixes, UI polish and safer defaults.

**Chats**
- "New messages" divider when opening a chat with unread messages; incoming messages no longer move the history you're reading
- Group and channel bubbles show the sender (and role icon) inside the bubble, avatar on top
- Timestamps and receipts sit inside the bubble, also for short replies and emoji
- Captions sent with files, images and voice messages are shown
- New setting: Appearance → Typing → "Enter sends messages"

**Fixes**
- Relaunching while in the tray no longer fails with "database is locked" (single instance)
- On-screen keyboard stays up while you scroll and tap in a chat; Enter from it always sends
- Voice messages on ARM phones: failures are shown above the composer instead of vanishing
- Deleting a group you don't own now leaves it first, as the official apps do
- A moderator's open support thread updates on new messages

**Privacy**
- "Remove tracking from links" now cleans links in messages you send, not only links you open
