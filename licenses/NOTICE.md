# Cursus — licenses and sources

Every Cursus package ships this folder with [`LICENSE`](../LICENSE): the
Flatpak and AppImage (`share/licenses/`) and the macOS app
(`Contents/Resources/licenses`, also under Settings → About → Licences).
Each entry says which builds contain it.

| **SimpleX Chat core 7.1.0.17** (`libsimplex`, its `libHS*` Haskell libraries, GHC runtime, `libffi`; on macOS also `libcrypto.3.0.dylib`) | Linux, macOS | AGPL-3.0 | simplex-chat [`1fd7ed8327d8481299215ca3240eb0140400924a`](https://github.com/simplex-chat/simplex-chat/tree/1fd7ed8327d8481299215ca3240eb0140400924a) with simplexmq [`d1f97d38f7a01f112efb6be753a1b45a40777826`](https://github.com/simplex-chat/simplexmq/tree/d1f97d38f7a01f112efb6be753a1b45a40777826); prebuilt from [simplex-chat-libs `core-7.1.0.17`](https://github.com/simplex-chat/simplex-chat-libs/releases/tag/core-7.1.0.17) |

`THIRD_PARTY_LICENSES.txt` and `SIMPLEX-CORE-LICENSES.txt` are generated by `scripts/third-party-licenses.py`;
re-run it whenever `Cargo.lock` or the SimpleX core change.

GMP is used under the GNU LGPL v3 (texts in `SIMPLEX-CORE-LICENSES.txt`).
Where it is linked statically (macOS), the complete corresponding
source of everything it is linked with is public (Cursus and SimpleX Chat,
links above; GMP at https://gmplib.org), so the linked work can be rebuilt
with a modified GMP.

The Flatpak runtime (org.freedesktop.Platform), the AppImage runtime and
the operating systems' own libraries (Linux system libraries, macOS
frameworks) are not part of these packages'
own code; they carry their own licenses.
