# Cursus — licenses and sources

Every Cursus package ships this folder with [`LICENSE`](../LICENSE): the
Flatpak and AppImage (`share/licenses/`), the macOS app
(`Contents/Resources/licenses`, also under Settings → About → Licences) and
the Android APK (Settings → About → Licences and credits). The same files
cover all three apps; each entry says which builds contain it.

`THIRD_PARTY_LICENSES.txt`, `SIMPLEX-CORE-LICENSES.txt` and
`ANDROID-LIBRARIES.txt` are generated by `scripts/third-party-licenses.py`;
re-run it whenever `Cargo.lock`, the SimpleX core or the Android
dependencies change.

GMP is used under the GNU LGPL v3 (texts in `SIMPLEX-CORE-LICENSES.txt`).
Where it is linked statically (Android, macOS), the complete corresponding
source of everything it is linked with is public (Cursus and SimpleX Chat,
links above; GMP at https://gmplib.org), so the linked work can be rebuilt
with a modified GMP.

The Flatpak runtime (org.freedesktop.Platform), the AppImage runtime and
the operating systems' own libraries (Linux system libraries, macOS
frameworks, Android platform libraries) are not part of these packages'
own code; they carry their own licenses.
